ENG-142  Checkout fails when a coupon code has trailing whitespace
state: In Progress   assignee: Maya Patel   priority: Urgent
https://linear.app/northwind/issue/ENG-142/checkout-fails-when-a-coupon-code-has-trailing-whitespace

Customers who paste a coupon code from our emails get **"This code is not valid"** at the last step of checkout. The pasted text ends with a space or a newline.

## Steps to reproduce

1. Add any item to the cart.
2. Paste `WELCOME10 ` (with the trailing space) into *Coupon code*.
3. Click **Pay now**.

Expected: 10% off. Actual: a 422 from `POST /api/checkout/confirm`:

```json
{
  "error": "coupon_invalid",
  "code": "WELCOME10 "
}
```
