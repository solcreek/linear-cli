An agent-first CLI for Linear: every command takes --json, every change takes
--dry-run or --yes, and 'linearctl describe' prints the whole surface as JSON.

The API key comes from LINEAR_API_KEY, else from 'linearctl auth login'.
LINEARCTL_HOME moves config and credentials under one directory.

Usage:
  linearctl [flags]
  linearctl [command]

Examples:
  linearctl issue list --assignee me --json
  linearctl describe

Available Commands:
  api          Send your own GraphQL query to Linear
  auth         Store, check or remove the Linear API key
  comment      List and create comments on an issue
  completion   Generate the autocompletion script for the specified shell
  config       Show or change settings
  cycle        List, show, create, update and archive cycles
  describe     Print every command, flag and exit code as JSON
  file         Download files attached to issues and comments
  help         Help about any command
  issue        List, show, create, update and archive issues
  label        List issue labels
  milestone    List project milestones
  notification List your inbox notifications, newest first
  project      List, show, create and update projects
  relation     Create and delete relations between issues (blocks, duplicate, related)
  serve        Answer linearctl invocations over stdin and stdout, one JSON line each
  state        List workflow states, by team and position
  team         List teams
  user         List users in the workspace
  view         List saved custom views
  watch        Stream changes to the issues a filter matches, one JSON line each

Flags:
      --demo        use a built-in fictional workspace: no key, no network; or LINEARCTL_DEMO=1
  -h, --help        help for linearctl
      --json        print one JSON document on stdout
      --meta        add meta (requests sent, rate limit left) to --json; or LINEARCTL_META=1
      --timeout N   give up on a network request after N seconds (default 30)
      --version     print the version

Use "linearctl [command] --help" for more information about a command.

Exit codes: 0 ok, 1 failed, 2 usage, 3 partial, 4 busy, 5 auth (no API key, or
Linear rejected it), 6 rate-limited (retry after retryAt), 7 conflict (it changed since
you read it; read it again)
Run 'linearctl describe' for every command as JSON.
